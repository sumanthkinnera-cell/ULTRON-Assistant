# DIMENSION --- Futuristic Smartphone Interaction

## Concept

An experimental smartphone app that explores interaction with digital
spaces beyond a conventional app or basic AR overlay. The exact core
experience still needs to be defined and validated.

## Prototype directions

-   Interactive 3D spatial scene.
-   Gesture/touch-driven portals and layered information.
-   Camera-based AR only where supported and permission is granted.
-   User-created spaces, objects, and transitions.
-   Mobile performance mode for lower-powered devices.

## Suggested technical path

1.  Create a mobile-first web prototype.
2.  Build one memorable interaction rather than many incomplete
    features.
3.  Use a 3D web library such as Three.js only after confirming device
    performance.
4.  Test on the actual Android phone.
5.  Measure load time, frame rate, usability, and battery impact.

## Risks and reality check

A website cannot create physical dimensions or bypass phone hardware
limits. Advanced AR requires supported hardware/browser APIs or a native
app. Treat novel interactions as experiments until user testing confirms
they are useful.
